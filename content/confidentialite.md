## En résumé

- **Aucune donnée n'est envoyée sur un serveur.** Les noms, adresses et montants que vous saisissez restent dans votre navigateur.
- **Aucun cookie**, aucun outil de mesure d'audience, aucun traceur, aucune publicité.
- **Aucun compte** : nous ne connaissons ni votre identité, ni celle de vos locataires.

## Comment c'est possible ?

Tout le travail se fait sur votre appareil :

1. Le formulaire, l'aperçu et le fichier agenda (.ics) sont calculés dans votre navigateur.
2. Les informations du bail sont rangées dans le lien de vos rappels, **après le signe « # »**. Par conception, cette partie d'une adresse web n'est jamais transmise au serveur qui héberge le site : elle n'apparaît donc dans aucun journal de connexion.
3. Le PDF de la quittance est fabriqué sur votre appareil, avec un module chargé depuis ce site. Aucun service extérieur n'est appelé.

Le service d'hébergement qui diffuse les pages du site enregistre, comme tout serveur web, des données techniques de connexion (adresse IP, page demandée, date). Ces journaux ne contiennent jamais les informations de vos baux.

## Ce qui est conservé sur votre appareil

- **Un brouillon du formulaire**, le temps de la session de navigation (stockage de session du navigateur), pour ne pas tout perdre si vous rechargez la page. Il disparaît à la fermeture de l'onglet.
- **Votre signature**, uniquement si vous cochez « Mémoriser sur cet appareil » (stockage local du navigateur). Décochez la case pour l'effacer.

## Attention à ce que vous partagez

Le fichier agenda et le lien de vos rappels **contiennent les informations du bail** (noms, adresses, montants). Si vous partagez votre agenda avec d'autres personnes, ou si vous transférez le lien, ces personnes pourront lire ces informations. Votre agenda en ligne (Google, Apple, Microsoft…) conserve ces événements selon ses propres règles.

## Responsabilité des données

En utilisant l'outil pour vos locations, vous restez responsable des données personnelles de vos locataires que vous saisissez et transmettez. Nous n'y avons pas accès.
