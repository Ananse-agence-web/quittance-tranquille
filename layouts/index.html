Le fichier agenda et le lien contiennent les informations du bail (noms, adresses, montants). Si vous partagez votre agenda, vous partagez aussi ces informations.

Comment ajouter le fichier à mon agenda ?

iPhone / Mac : ouvrez le fichier téléchargé, puis « Tout ajouter ».

Google Agenda : sur ordinateur, Paramètres › Importer et exporter › Importer. Google applique ses propres notifications par défaut aux événements importés : vérifiez-les sur le premier rappel.

Outlook : ouvrez le fichier, ou Calendrier › Ajouter un calendrier › Charger à partir d'un fichier.

Vous changez d'avis ? Supprimez les événements « Loyer de… » puis importez le nouveau fichier.

Tout est calculé ici, dans votre navigateur. Aucune donnée n'est envoyée sur un serveur : ni les noms, ni les adresses, ni les montants.

Vos données restent chez vous

Pas de compte, pas de base de données, pas de cloud. Les informations du bail sont rangées dans le lien de votre rappel, après le signe « # » : cette partie d'une adresse web n'est jamais transmise au serveur.

  • La quittance est calculée et mise en PDF sur votre téléphone ou votre ordinateur.
  • Le rappel vit dans votre propre agenda, pas chez nous.
  • Aucun cookie, aucune mesure d'audience, aucun traceur.
  • C'est vous qui envoyez la quittance, quand vous avez bien reçu le loyer.
